小纸慢读 · Pico OS 通过 USB 连接设备后开始
请使用最新版 Chrome 或 Edge，并通过 HTTPS 打开此页面。 浏览器需要安全连接（HTTPS）才能访问 USB。
01

准备设备

使用支持数据传输的 USB 线连接小纸 Pico。若浏览器未识别设备，请换用 USB-A 数据线；仍未识别时，让设备睡眠并唤醒，或重启后再试。设备没有实体 BOOT / RESET 键。

02

选择串口

点击“连接并安装”，在系统弹窗中选择小纸 Pico 对应的 USB 串口。

03

等待完成

刷写期间保持连接。浏览器显示完成后，断开 USB 并重新启动设备。

刷写前请留意
  • 首次安装会提示是否擦除设备 Flash。擦除会清除 ESP 内置存储中的数据与设置；TF 卡文件不受影响。
  • 不要在刷写过程中拔线或关闭页面。失败时可重新进入下载模式，再试一次。
  • 此固件面向小纸 Pico（ESP32-S3、16 MB Flash、8 MB PSRAM），不要用于其他板子。
