# Pico OS · 第一阶段产品与界面基线

## 产品定位

Pico OS 是面向 Read Pico（小纸 Pico）硬件的轻量墨水屏系统界面。它优先提供清晰的阅读入口、设备信息和联网传输能力，不以复刻手机操作系统为目标。

## 已确认的设计决策

2026-11 更新：Pico OS 从“桌面加平铺演示菜单”调整为固件原生应用框架。硬件演示仍作为板级排障工具保留，但统一收进“系统工具”；设备功能自检保留在一级菜单。原因是阅读、传书、看板和设备管理已经形成面向用户的固件功能，原菜单层级却仍把 Pico OS 当作众多演示页之一。

| 维度 | 决策 | 落地要求 |
| --- | --- | --- |
| 视觉 | 极简 Apple 风格 | 大量留白、克制的黑白灰、清晰层级、精致排版；避免装饰性渐变和高密度卡片 |
| 联网 | 联网型 | Wi-Fi 是获取与同步信息的主要通道；离线时桌面、阅读和本地内容仍可使用 |
| 交互 | 混合交互 | 触控与屏下三键都能完成主要导航和确认；不能把关键操作只放在触控上 |

## 第一阶段目标

1. Pico OS 桌面作为默认启动页，提供图书、Wi-Fi 传输、设备状态和应用菜单入口。
2. 一级应用菜单突出图书、传书、设备状态、个人看板、设备自检和系统工具。
3. 系统工具将显示、触摸、传感器、电源、按键、存储、字体和睡眠诊断放在二级入口；不删除已有板级诊断能力。
4. 触控点按与 KEY1 移动焦点、KEY2 确认、KEY3 打开应用菜单；长按 KEY2 执行整屏 GC16 强刷。
5. 无 Wi-Fi 时仍可进入本地阅读、看板和设备功能。

## 视觉规范 v0.1

- 画布按竖屏逻辑分辨率 684 × 1216 排版。
- 采用白底、黑色文字和少量浅灰分隔；不使用彩色状态装饰。
- 标题、说明、操作提示分层；正文与关键操作保持易读字号。
- 主入口采用宽松的 2 × 2 网格，避免小目标和密集列表。
- 墨水屏交互优先考虑整页刷新与残影控制，不为动画牺牲可读性。

## 架构边界

- Pico OS 桌面是默认启动页；一级应用注册表不再把桌面当作普通菜单应用列出。
- 一级应用由 `app_registry.c` 管理，硬件诊断由 `app_system_tools.c` 的二级工具表管理。
- 应用切换仍由既有 app_loop 调度；页面不直接操作底层 I2C、PMU 或显示电源。
- 图书、Wi-Fi 传输、字体、存储与硬件诊断继续复用现有实现；调整菜单分层不移除任何已有工具页。
- Wi-Fi 连接状态、同步协议与后台任务将在后续阶段单独设计；本阶段不伪造联网状态。

## 验收标准

- ESP-IDF v6.1 下 CI 配置可编译。
- 真机启动后默认进入 Pico OS 桌面。
- 桌面四个入口可通过触控和三键完成导航。
- 一级菜单显示六个固件应用入口；系统工具中可导航到全部硬件诊断页。
- 图书、传输、设备自检和诊断入口可正常打开并通过应用菜单切换。
- 离线状态下桌面仍可启动，不依赖 Wi-Fi 初始化成功。
