# Pico OS · 第一阶段产品与界面基线

## 产品定位

Pico OS 是面向 Read Pico（小纸 Pico）硬件的轻量墨水屏系统界面。它优先提供清晰的阅读入口、设备信息和联网传输能力，不以复刻手机操作系统为目标。

## 已确认的设计决策

| 维度 | 决策 | 落地要求 |
| --- | --- | --- |
| 视觉 | 极简 Apple 风格 | 大量留白、克制的黑白灰、清晰层级、精致排版；避免装饰性渐变和高密度卡片 |
| 联网 | 联网型 | Wi-Fi 是获取与同步信息的主要通道；离线时桌面、阅读和本地内容仍可使用 |
| 交互 | 混合交互 | 触控与屏下三键都能完成主要导航和确认；不能把关键操作只放在触控上 |

## 第一阶段目标

1. 增加独立桌面入口，不替换或破坏原厂 BSP、显示驱动、PMU、睡眠和字体系统。
2. 桌面提供图书、Wi-Fi 传输、设备状态和全部应用四个入口。
3. 触控点按与 KEY1 / KEY2 / KEY3 完成相同的核心导航。
4. 原厂诊断概览仍可从桌面进入；原有图书与传输功能继续复用。
5. 无 Wi-Fi 时仍可进入本地阅读和设备功能。

## 视觉规范 v0.1

- 画布按竖屏逻辑分辨率 684 × 1216 排版。
- 采用白底、黑色文字和少量浅灰分隔；不使用彩色状态装饰。
- 标题、说明、操作提示分层；正文与关键操作保持易读字号。
- 主入口采用宽松的 2 × 2 网格，避免小目标和密集列表。
- 墨水屏交互优先考虑整页刷新与残影控制，不为动画牺牲可读性。

## 架构边界

- 新桌面作为独立 app_desc_t 页面加入注册表。
- 应用切换仍由既有 app_loop 调度；页面不直接操作底层 I2C、PMU 或显示电源。
- 图书、Wi-Fi 传输、字体、存储与硬件诊断继续复用现有实现。
- Wi-Fi 连接状态、同步协议与后台任务将在后续阶段单独设计；本阶段不伪造联网状态。

## 验收标准

- ESP-IDF v6.1 下 CI 配置可编译。
- 真机启动后默认进入 Pico OS 桌面。
- 四个入口可通过触控和三键完成导航。
- 原厂图书、传输、诊断入口可正常打开和返回。
- 离线状态下桌面仍可启动，不依赖 Wi-Fi 初始化成功。
